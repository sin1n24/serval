# Serval — トーナメント管理システム

作成フェーズと運用フェーズを行き来できる、単一HTMLのトーナメント管理ツール。
バックエンドに Google Apps Script（GAS）を想定しつつ、HTMLを直接開いた場合は
localStorage に自動フォールバックして単独でも動作します。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 本体（UI・ロジック・CSSすべて内包） |
| `Code.gs` | GASバックエンド（`doGet`でHTML配信、保存/読込/結果送信API） |
| `appsscript.json` | GAS Webアプリ設定 |

## 使い方（単独・スタンドアロン）

`index.html` をブラウザで開くだけで動作します。データはブラウザの localStorage に保存されます。

## 使い方（GASホスト）

1. Google Apps Script プロジェクトを作成
2. `Code.gs` / `index.html` / `appsscript.json` を取り込み
3. ウェブアプリとしてデプロイ（アクセス: 全員）
4. 発行URLを開く（フロントは `google.script.run` 経由でスプレッドシートに保存）

## 主な機能

### 作成フェーズ
- トーナメント基本サイズ 4〜128、1〜4トーナメント、選手数からの自動算出
- シード（不戦枠は繰り上げて縦詰め表示）、3位決定戦
- 通常スタイル / 中央決勝（左右対向）スタイル
- 上下の色（6色編集可能パレット）、枠サイズ調整、ダーク/通常テーマ
- 名前リスト・CSV取込（UTF-8/Shift_JIS）、ランダム配置、同所属の初戦回避、D&D編集
- 試合番号の常時表示

### 運用フェーズ
- 試合番号クリックで結果入力（勝者・勝ち方：1本先取/2本先取/不戦勝/勝者なし）
- 送信→OKで進行、勝者の線が太線＋色（色変更可）
- 試合番号の上下に勝ち数を表示
- 演出（対戦カード大写し）、試合時間記録（任意）

## データ入出力
- JSON 保存/読込/書き出し/取込（書式バージョン付き）
- CSV 取込（選手名・所属・番号・代表者・連絡先）
