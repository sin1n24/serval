# Serval — トーナメント管理システム

単一HTMLで動くトーナメント／リーグ運営ツール。**閲覧モード**（観客・スマホ向け、自動更新）と**管理モード**（作成・結果入力）を1画面で切り替えて使えます。バックエンドに Google Apps Script（GAS）＋スプレッドシートを想定しつつ、HTML を直接開いた場合は localStorage に自動フォールバックして単独でも動作します。

公開デモ（スタンドアロン／GitHub Pages）: https://sin1.studio/serval/

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 本体（UI・ロジック・CSS をすべて内包） |
| `Code.gs` | GAS バックエンド（`doGet` で HTML 配信、保存/読込/結果送信 API） |
| `appsscript.json` | GAS ウェブアプリ設定 |

## 使い方（単独・スタンドアロン）

`index.html` をブラウザで開くだけで動作します。データはブラウザの localStorage に保存されます。

## 使い方（GAS ホスト）

1. Google Apps Script プロジェクトを作成
2. `Code.gs` / `index.html`（小文字）/ `appsscript.json` を取り込み
3. ウェブアプリとしてデプロイ（アクセス: 全員）
4. 発行 URL を開く（保存・閲覧の自動更新がスプレッドシート経由になります）

> clasp を使う場合は `clasp push` → `clasp create-version` → `clasp redeploy <deploymentId> --versionNumber N` で更新できます。

## モード

- **閲覧モード（既定）**: 操作 UI を隠し、ブラケットのみを表示。約7秒ごとに自動更新。観客・スマホ向け。
- **管理モード**: タイトルを**トリプルクリック**→パスワードで切替（簡易・非セキュア）。URL に `#admin` を付けて開くと最初から管理モード（ローカル/通常ホスティング時）。
  - パスワードは `index.html` 内の定数 `ADMIN_PASS`（要変更）。
- 作成と運用は統合：管理モードでは枠の編集・D&D と試合番号クリックでの結果送信が同時に行え、勝者線も常時反映されます。

## 主な機能

### ブラケット
- 基本サイズ 4〜128、1〜4 トーナメント（ブロック）、選手数からの自動算出
- シード（不戦枠は繰り上げ表示）、**逆シード**（シードが多数のブロックでは非シード戦を優先採番）
- 3位決定戦（あり/なし、ドラッグで位置移動）
- 通常スタイル／中央決勝（左右対向）スタイル
- 上下の色（6色編集可能パレット）、枠サイズ・テーマ（ダーク/通常）・表示倍率
- 名前リスト・CSV 取込（UTF-8/Shift_JIS）、ランダム配置、**同所属の初戦回避**（入替修復つき）、D&D 編集
- スマホのピンチイン/アウトで表示倍率変更

### 運用
- 試合番号クリックで結果入力（勝者・勝ち方：1本先取/2本先取/不戦勝/勝者なし、試合時間）
- 結果の**取り消し（未送信に戻す）**、致命的変更・試合後の D&D/シード変更には確認ダイアログ
- **勝ち上がり演出**（火花→勝者拡大・敗者縮小＋赤線）→ **対戦カード演出**（次の試合）を連続再生し、該当試合の勝者線を点滅
- 演出は管理側の操作を**閲覧側にも配信**
- 画面下部に**次の試合バー**（次の試合／2番手／3番手＋スキップ、合計最大4件）。試合のスキップ・「この試合を次の試合にする」
- 順位表（単独/代表トーナメントは 優勝・準優勝・3位、代表リーグは 本数勝→本数負→総試合時間）
- **呼出**ボタン（別システム連携用フック。`CALL_ENDPOINT` 設定で番号を POST）

### 代表戦（複数ブロック時）
- 代表トーナメント、または代表リーグ戦（3ブロック時、2名トーナメント×3を縦並べ）

## データ入出力
- JSON 保存/読込/書き出し/取込（書式バージョン付き）
- CSV 取込（選手名・所属・番号・代表者・連絡先）
